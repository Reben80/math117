Section 2.1

Three pictures

01

Stem-and-leaf

Every value stays on the page. Use it when the list is short.

02

Line graph

A point for each value, connected. The height is how often it happened.

03

Bar graph

Separate bars, one per category. The bars do not touch.

A graph shows where the data cluster, and where they thin out.

Descriptive statistics is this chapter: display the data, then describe the center and the spread. Graph first, then calculate.

Example 2.1 · Read the plot

Now answer the warm-up

1   How many students scored below 60?

✓ 7 of 31  (33, 42, 49, 49, 53, 55, 55), about 23%.

2   Which score happened most often?

✓ 94. It appears four times on stem 9.

3   If 70 is passing, what percent passed?

✓ 4 + 5 + 7 + 1 = 17 of 31, about 55%.

4   Hard test or easy test? Defend it with the plot.

✓ Open: just over half scored 70+, but a long low tail reaches 33. Both views can be argued.

Ask each question, give 20 to 30 seconds, then click for the answer. Students should count from the plot, not the list. Q3: stems 7, 8, 9, 10 have 4, 5, 7, 1 leaves. Check: below 70 is 1+3+3+7 = 14, and 14 + 17 = 31. Q4 has no single right answer; push for evidence from the plot (where the cluster is, how far the tail reaches). This is the habit for the whole chapter: graph first, then talk about shape, center, and spread.

Example 2.2 · Think it through

What should we do with 12.3 km?

A classmate says: “Delete it. It ruins the graph.” Do you agree?

1 · Check it

Is it a typo?

Could 1.23 or 2.3 have been typed as 12.3? Go back to the source if you can.

2 · If it is real, keep it

It is information

Maybe one store really is far away. That fact is part of the data.

3 · Report it

Say what you did

If you leave a value out, tell the reader which one and why.

An outlier is a question, not a mistake. Never delete a value only because it is inconvenient.

Two minutes. Take a quick show of hands on the classmate's claim before showing the cards (the cards are on screen, so you may want to ask the question while still on the previous slide). The book's own example of a mistake: writing 50 instead of 500. Later in Unit 2 (section 2.3) students get a rule for flagging outliers: below Q1 - 1.5 IQR or above Q3 + 1.5 IQR.

Spot the mistake · 3 minutes

Someone drew Example 2.6 as a line graph

1   What would the point halfway between Midwest and South mean?

✓ Nothing. There is no region halfway between two regions.

2   Which graph should it be, and why?

✓ A bar graph. Region is a category, so the bars stay apart.

3   Why was a line graph fine for the chores data?

✓ 0, 1, 2, … 5 reminders are numbers in order, so connecting them makes sense.

Real data from Table 2.11 (Northeast 16.1%, Midwest 21.6%, South 39.0%, West 23.3%), deliberately drawn wrong. Point: a connecting line claims there is an order and in-between values. Categories have neither. If someone says 'you could reorder the regions and get a different line', that is exactly the point: the shape of the line is meaningless.
