Frequency and relative frequency

A count, and a count divided by n

Frequency

How many times the value happens.

Three students scored from 90% to 100%.

Relative frequency

The count divided by n.

3 / 40 = 0.075, which is 7.5%.

The bars of a histogram touch. A bar graph of categories leaves a gap. Use a histogram once the list is long. A common rule of thumb is about 100 values or more.

Book sentence: RF = f/n. English class, f = 3, n = 40, RF = 0.075. 90 to 100 percent are measurements, so a histogram fits. Choose 5 to 15 classes. A rough guide some people use is about the square root of n bars. The square root of 150 is about 12. The book still lets you choose.

Example 2.7 · continuous heights

Start just below the smallest value

Smallest height 60. Start at 59.95.

Largest height 74. End at 74.05.

Eight bars. Width (74.05 − 59.95) / 8 = 1.7625.

Round the width up to 2.

The extra decimal keeps a height off the boundary line. Rounding up can go against ordinary rounding, and that is allowed. A height on the left edge belongs to that bar. A height on the right edge belongs to the next bar. More than one correct histogram is possible.

Same 100 players as Table 1.13. Continuous, to the nearest half inch. Boundaries: 59.95, 61.95, 63.95, 65.95, 67.95, 69.95, 71.95, 73.95, 75.95. The book notes that a width of 1.76 would also work. If every value is a whole number and the smallest is 2, the book starts at 1.5. If the most precise value is 6.1 and it is the smallest, start at 6.05.

Example 2.8 · counted books

A histogram can be made of counts

The bars still touch. Start at 0.5 and end at 6.5, so each count sits in the middle of a bar of width 1. The bar for 3 books runs from 2.5 to 3.5. Sixteen of the 50 students bought three books.

Eleven, ten, sixteen, six, five, and two students. The six frequencies add to 50. Calculator, in the notes only: L1 is 1 through 6, L2 is 11, 10, 16, 6, 5, 2. Window Xmin 0.5 and Xmax 6.5. Histogram plot, not a bar graph. Try It 2.8: 50 athletes. 20 play one sport, 22 play two, 8 play three. Same kind of histogram.

Example 2.10 · a frequency polygon

Connect the class frequencies

Each point is a class. The labels are the middles: 54.5 holds the five scores from 49.5 to 59.5. The empty points at 44.5 and 104.5 bring the line down to the axis. The two sides are not mirrors, so the book calls the shape skewed.

Table 2.14. Classes 49.5-59.5, 59.5-69.5, 69.5-79.5, 79.5-89.5, 89.5-99.5. Frequencies 5, 10, 30, 40, 15. Cumulative 5, 15, 45, 85, 100. The peak is the class centered at 84.5. Try It 2.10 is presidential age at inauguration. Leave the overlay polygons, Example 2.11, unless a student asks.

Example 2.12 · a time series

The same measurement, in time order

The picture above is only the shape. The book’s graph is the consumer price index, every month, for ten years. Connect the points in calendar order. Do not change the time unit halfway across, and do not stretch an axis to exaggerate a change.

Table 2.19 is a long monthly table. Do not copy it onto a slide. The teaching point is the order: time on the horizontal axis, the measurement on the vertical axis. The book’s caution, just before section 2.3: a time series is easy to distort by changing units mid-axis or by stretching one axis. Purposeful manipulation is presented there as unethical.
